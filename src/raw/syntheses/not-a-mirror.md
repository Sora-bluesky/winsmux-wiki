# 正本との差分

このサイトは、公式 docs の全ページを日本語にしたものです。正本は常に [公式 docs](https://hermes-agent.nousresearch.com/docs/) です。食い違っていたら、公式が正しいと考えてください。

## 公式と同じもの

- 全ページの構成。見出しの数・順序・階層、コード、コマンド、設定値、リンク先は公式とバイト単位で一致させています（機械照合済み）
- 手順の順序。足したり引いたりしていません

## 公式と違うもの

- 言語。本文の散文は日本語です
- 入口。トップページの案内と、運用・どこまで任せるか・しくみの短い説明は、このサイト独自です
- 画面。サイドバー・検索・目次・AI に渡すバーは、このサイトの作りです

## 追従のしかた

上流の docs の変化を毎日 1 回確認し、変わったページだけ訳し直します。各ページの下の「正本:」リンクから、いつでも公式の原文に飛べます。
