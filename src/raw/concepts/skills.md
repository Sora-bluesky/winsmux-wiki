# Skills

skill は、あとから足せる知識です。「このやり方でやって」という手順書をファイルで持たせておくと、Hermes は必要なときだけそれを読んで従います。ふだんは読み込まれないので、会話が重くなりません。

最初から入っている skill が約 90、あとから入れられるものが約 60 あります。Hermes が作業の中で自分用の skill を作ることもあり、使われなくなったものは Curator という保守機能が整理します。

- しくみ — [Skills System](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills)
