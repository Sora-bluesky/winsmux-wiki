# CLI の記号集 {#cli-symbols-glossary}

Hermes の端末の画面は、点、山形、点字のくるくる、状態を表す小さな絵といった、短い見た目の言葉で話しかけてきます。このページは、その解読の手引きです。多くが描かれる [TUI](/hermes/docs/user-guide/tui/) を中心に扱い、[旧来の CLI](/hermes/docs/user-guide/cli/) と共通の部分にも触れます。

:::note 見た目は着せ替えで変えられるものがあります
下の表で *着せ替え可* と書いたものは、もともと決めてある見た目です。[着せ替え](/hermes/docs/user-guide/features/skins/)で上書きできます（例えば `tool_prefix` と入力行の記号）。それ以外は描画する側で固定してあります。
:::

## 会話の流れに出る記号 {#transcript-symbols}

エージェントが働いているあいだ、やりとりの流れの中で目にするものです。

| 記号 | 意味 |
|--------|---------|
| `❯` | 入力の行です。ここに打ちます。*着せ替え可*（着せ替えは自前の記号を決めます）。 |
| `●` | ツールの呼び出しです。この点のあとに、ツールの名前と引数が続きます。 |
| `┊` | ツールの動きに沿って引かれる縦線です。*着せ替え可*（`tool_prefix`）。 |
| `✓` / `✗` | ツールの結果で、成功／失敗を表します。終わったツールの行の末尾に付きます。 |
| `▸` / `▾` | たたんである／開いてある、を示す山形です（思考、ツール、下請けのエージェント、見出しの各部分）。押すと切り替わります。 |
| `▍` | 流れている位置を示す印です。モデルがまだ文章を出しているあいだ点滅します。 |
| `│` `├─` `└─` | 枝を結ぶ線です。親（任せた作業、たどってきた道筋）と、その下の項目をつなぎます。`└─` は最後の子を表します。 |
| `◈` | 表示のためだけの出来事です（セッションのお知らせがその場に描かれたもので、利用者のメッセージではありません）。 |
| `◇` | 差し込まれた参照のかたまりです。例えば `◇ Reference 1/2 — <label>` のように出ます。 |
| `↳` | 貼り付いたままの指示です。エージェントがいま取り組んでいる利用者のメッセージを映しています。 |
| `☐` / `☑` / `•` | Markdown のやることの一覧（未了／完了）と、ふつうの箇条書きの点です。 |
| `▶` | 描かれた Markdown の中で、たたんである `<details>` の見出しです。 |

## 下段に出る記号 {#status-bar-symbols}

TUI のいちばん下に出る一行です。各区画は必要なときだけ現れ、端末の幅が狭いと真っ先に消えます。

| 記号 | 意味 |
|--------|---------|
| `⠋⠙⠹…`（点字の模様） | 動いていることを示すくるくるです。考えているときとツールを使っているときで、点字の動かし方が変わります。 |
| `⚕ 🌀 🤔 ✨ 🍵 🔮` | `emoji` の動作表示（`/indicator emoji`）のこまです。もともとの表示では、代わりに顔文字が入れ替わります。 |
| <code>&#124; / - &#92;</code> | `ascii` の動作表示のこまです。 |
| `⏱` | ひとつの指示にかかっている時間です。作業中に `⏱ 12s/3m 45s` のように出ます（この回の時間／セッション全体の時間）。 |
| `⏲` | 同じ時計で、その回が終わったあとに止まったものです。 |
| `cmp N` | このセッションが自動で N 回まとめ直されたことを表します。 |
| `▶ N` | いま動いている `/background` の作業が N 件あります。 |
| `⚠ YOLO` | YOLO の状態（自動で承認する）です。起動時の見出しにも出ます。 |
| `⛓ N` | いま動いている下請けのエージェントが N 件あります。 |
| `↩ resumes when subagent finishes` | 手が空いていても、任せた作業がまだ進んでいるときに出る知らせです。結果はひとりでに返ってきます。 |
| `● REC` | 声の入力が録れています。 |
| `◉ STT` | 声の録音が止まり、文字に起こしているところです。 |
| `◉ focus` | 出力を絞る表示になっています。狭い端末でも消えないよう留めてあります。 |
| `♥` | やさしくされたことに Hermes が気づいた、というひらめきです。 |
| `⚡` / `🔋` | 電池の表示（自分で入れます）で、電源につないでいる／電池で動いている、を割合とともに出します。 |
| `N bg` | このセッションで見ている、裏で動く端末のプロセスが N 件あります。 |
| `N live sessions` | この処理の中で開いている TUI のセッションの数です。押すとセッションの切り替え画面が開きます。 |

## お知らせ {#notices}

下段に短いあいだ出るお知らせには、重さに応じた記号が先頭に付きます。

| 記号 | 意味 |
|--------|---------|
| `✓` | うまくいったお知らせです。 |
| `•` | 参考までのお知らせです。 |
| `⚠` | 注意です（残りの利用枠の注意にも使います）。 |
| `✕` | 失敗のお知らせです。 |

## 承認と確認の画面 {#approval-and-confirmation-prompts}

| 記号 | 意味 |
|--------|---------|
| `⚠ approval required` | ツールが、はっきりした承諾の要ることをしようとしています（枠付きの囲みに、走らせるコマンドが添えられます）。 |
| `⚠` / `?` | 確認の画面の見出しで、危ない操作／ふつうの問いかけを表します。 |
| `🔐` | sudo のパスワードの入力です（打った内容は隠れます）。 |
| `🔑` | 資格情報や秘密の入力です（打った内容は隠れます）。 |

## 下請けのエージェントの画面（`/agents`） {#subagents-overlay-agents}

| 記号 | 意味 |
|--------|---------|
| `●` | 下請けのエージェントが動いています。 |
| `○` | 順番待ちです。 |
| `✓` | 終わりました。 |
| `■` | 途中で止められました。 |
| `✗` | 失敗しました。 |
| `⌛` | 時間切れです。 |
| `⚠` | 異常が起きました。 |
| `⚡N` | まとめた行の中で、いま動いているエージェントが N 件あります。 |
| `▁▂▃▄▅▆▇█` | 動きの折れ線です。枝ごとの、最近の出来事の多さを表します。 |

## セッションの切り替え画面（`Ctrl+X`） {#session-switcher-ctrlx}

| 記号 | 意味 |
|--------|---------|
| `✓` | セッションは手が空いています。 |
| `…` | 始まろうとしています。 |
| `?` | 入力を待っています。 |
| `▶` | 作業中です。 |
| `✎ draft` | そのセッションの入力欄に、送っていない書きかけが残っています。 |

## 選択画面と入り口 {#pickers-and-hubs}

| 記号 | 意味 |
|--------|---------|
| `▸` | いま選んでいる行です（モデルの選択画面など）。 |
| `*` | いま使っているモデルや提供元です。 |
| `●` / `○` | 提供元にログインできている／できていない（モデルの選択画面）。プラグインの入り口では、状態がわからないときの代わりの表示です。 |
| `✓` / `✗` | プラグインが有効／無効です（プラグインの入り口）。 |
| `↑ N more` / `↓ N more` | 見えている範囲の上／下に、まだ N 行あります。 |
| `┃` | 巻物のつまみです。巻いて見る画面に出ます。 |

## 目標 {#goals}

[目標](/hermes/docs/user-guide/features/goals/)のお知らせは、その状態を表す記号から始まります。

| 記号 | 意味 |
|--------|---------|
| `✓` | 目標を果たしました。 |
| `↻` | 目標は続いています。次の一巡が予定に入りました。 |
| `⏸` | 目標は止めてあります。 |
