# ローカル

手元のマシンにそのまま入れる形です。いちばん簡単で、Desktop アプリならインストーラを実行するだけで始まります。手元のファイルやアプリに直接触れるのが強みで、同時にそれが注意点でもあります。

ノート PC を閉じると Hermes も止まります。LINE や Telegram から常に使いたい場合は、この点が [VPS](/hermes/entities/vps/) との分かれ目になります。

ふだん使いのマシンに入れるときの守り方は、公式にまとまっています。

## 公式で読む

- 入れ方 — [Installation](https://hermes-agent.nousresearch.com/docs/getting-started/installation)
- Desktop アプリ — [Desktop App](https://hermes-agent.nousresearch.com/docs/user-guide/desktop)
- 仕事マシンでの守り方 — [Running Hermes on a Personal or Work Machine](https://hermes-agent.nousresearch.com/docs/guides/secure-hermes-on-a-work-machine)
- Windows で動かす — [Windows (Native) Guide](https://hermes-agent.nousresearch.com/docs/user-guide/windows-native) / [Windows (WSL2) Guide](https://hermes-agent.nousresearch.com/docs/user-guide/windows-wsl-quickstart)
