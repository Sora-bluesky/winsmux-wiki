# 日本語入力と日本語化の現在地

日本語で話しかけて日本語で返してもらう、という使い方に問題はありません。困るのはその手前、文字を打ち込むところです。このページは 2026-08-27 に GitHub で確認した内容だけで書いています。

## 日本語で使えるか

会話と応答は日本語で通ります。モデルに日本語で書けば日本語で返ってきますし、日本語で返してほしいと指示することもできます。

表示の決まり文句を日本語にする設定は `display.language` です。値は `ja` です。

```
hermes config set display.language ja
```

セッション単位で切り替えたいときは、環境変数 `HERMES_LANGUAGE` が設定の値より優先されます。

ただし、この設定が訳す範囲は狭いです。公式の[設定](/hermes/docs/user-guide/configuration/)は、対象が CLI の承認の確認と、ゲートウェイの一部のスラッシュコマンドの返事だけであり、エージェントの返事・ログ・ツールの出力・エラーの記録は英語のままだと書いています。他の言語でも同じ範囲の狭さが報告されています（#90662、open、2026-08-20、`display.language=zh` にしても実行中の状態表示が英語のまま）。

## 日本語入力の既知問題

日本語の入力そのものを名指しした報告は、2026-08-27 時点で1件です。

- **#94542**（open、2026-08-25）— デスクトップの Kanban で、変換確定の Enter がそのまま登録の Enter として扱われ、確定した時点で未完成のまま登録されます。報告環境は macOS 15.7.7 / v0.20.5 です。

同じ仕組みの問題は、中国語・韓国語の入力として多く報告されています。日本語でも同じ経路を通るため、あわせて見ておく価値があります。

- **#91624**（open、2026-08-21）— v0.20.4 以降、WezTerm + WSL2 で入力が2文字ずつ確定し、`/command` の行でカーソルキーが効きません。拡張キーボードの通知が入力の確定と噛み合っていない、と報告者が原因まで書いています。
- **#65467**（open、2026-07-16）— v0.18 で、Hermes のターミナルへ切り替えたあと入力そのものが止まります。
- **#84349**（open、2026-08-12）— TUI で非 ASCII の1文字ごとに約1秒の表示の遅れが出ます。
- **#48161**（open、最終更新 2026-07-25）— Windows で、次のキーを打つまで入力中の文字が表示されません。
- **#39457**（open、最終更新 2026-07-25）— macOS で、英語のあとに続けて打った文字が落ちます。
- **#40954**（closed、not planned、2026-07-14）— WSL2 + WSLg のデスクトップアプリで、Windows 側の入力が届きません。

回避策として書かれているものは、いまのところ2つだけです。#40954 には、Windows 側で動くデスクトップアプリを組み、バックエンドだけ WSL に置いてつなぐ手順が書かれています。ただしこの報告は not planned として閉じられており、公式の手順ではありません。#91624 には環境変数 `HERMES_DISABLE_EXTENDED_KEYS` を使う案がありますが、これは報告者が自分で当てた修正の前提での話で、その修正を取り込む PR（#91661）は 2026-08-27 時点でまだ開いたままです。設定するだけでは効きません。

公式 docs には、入力の不調に対する記述は見つけられませんでした。[Windows](/hermes/docs/user-guide/windows-native/) のページに文字コードの注意はありますが、入力の確定の話ではありません。

## UI の日本語化の現在地

日本語化を進める変更は出ていますが、2026-08-27 時点で取り込まれたものはありません。

- **#85723**（open、最終更新 2026-08-23）— 公式サイトへの日本語の追加。
- **#43537**（open、最終更新 2026-07-19）— 公式サイトへの日本語の追加と、主要ページの翻訳。
- **#54542**（open、最終更新 2026-07-19）— 日本語の訳語の範囲を広げるもの。
- **#22493**（closed、取り込まれずに閉じられた、2026-05-09）— ダッシュボードへの日本語の追加。

入力側の修正も同じ状態です。#94542 に対応する #94611 と #95245、TUI の確定を守る #39246 は、いずれも開いたままです。

公式の[デスクトップ](/hermes/docs/user-guide/desktop/)のページには、アプリの表示言語をアプリ内で切り替えられると書かれていますが、例として挙がっているのは簡体字中国語です。日本語が選べるかどうかは、この記述からは確認できませんでした。

公式 docs 自体は英語だけです。このサイトはその日本語版で、正本は公式にあります。
