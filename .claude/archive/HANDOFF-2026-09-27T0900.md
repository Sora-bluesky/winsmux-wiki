## 落とし穴（このレーンで実測したもの・詳細は archive）
- `wiki-ship` は「変更なし」で止まる前提にできない。流す前に `--dry-run` で件数を見る
- `git status --porcelain` は autocrlf 正規化だけで M を返す。内容差分は `git diff --name-only HEAD` + `ls-files --others`
- `grep -c` は行数であって回数ではない。1行圧縮 XML/HTML は必ず1になる（`grep -o | wc -l`）
- この環境の再帰 grep は実在文字列に 0 を返すことがある。`find | xargs grep` と突き合わせる
- HTTP 健全性検査は UA で落とされていないか先に切り分ける
