## 落とし穴（このレーンで実測したもの）
- **`wiki-ship` は「変更なし」で止まる前提にできない**。build が `updates.md` / `updates-weekly.md` を再生成するので、clean のつもりでも 4 件乗る。流す前に `--dry-run` で 3 段目の件数を見る（09-08 に `b186823` として無関係なメッセージでコミットされた）
- **`git status --porcelain` は autocrlf の正規化判定だけで M を返す**。内容差分の判定は `git diff --name-only HEAD` + `ls-files --others`
- **`grep -c` は行数であって回数ではない**。1 行に圧縮された XML/HTML では必ず 1 になる（`grep -o ... | wc -l`）
- **この環境の再帰 grep は実在する文字列に 0 を返すことがある**。`find ... -print0 | xargs -0 grep` と突き合わせる
- HTTP の健全性検査は UA で落とされていないか先に切り分ける（llms.txt が curl 200 / urllib 403）
